# 强度梯队（先验，待对局数据校正）

> ⚠️ 这是**未经对局验证的先验假设**，仅按"机制强度"推演，置信度低。
> 自对弈统计出来后必须按胜率重排。请勿当结论使用。

## 评估维度（每角色按这些打分）
- 续动作能力（额外行动链）
- 穿防/必中能力
- 爆士气效率（含 force-draw 配合）
- 冲杯/资源加速能力
- 自保/抗压（治疗、士气保底）
- 操作复杂度（越复杂越可能被内置AI低估）

## 先验高强度候选（待验证）
- 风之剑圣 / 剑之魔女 / 兽灵武士：连续行动链 + 穿防。
- 圣弓 / 原初之弓：圣煌辉光炮（星杯+1 且拉平士气，翻盘/冲杯双用）。
- 狂战士 + force-draw 配合：高攻爆士气。
- 圣殿骑士 / 红莲骑士：士气保底 + 自循环，抗压强。
- 星坠女巫 / 吟游诗人 / 灵熙之潮：高上限运营/AOE（复杂，易被内置AI低估）。

## 先验需观察是否偏弱/吃操作
- 纯辅助/纯治疗角色单独评估时偏弱，需看队伍协同。
- poXiao 低 HP 势力角色：上限/容错差异待测。

## 校正流程
1. 跑足量自对弈 → 按 win_rate 排序。
2. 区分"机制弱"与"被内置AI低估"（用 LLM/优化AI 复核高复杂度角色）。
3. 更新本表，confidence 随样本量提升。
