# 攻击、应战与系别/命格

## 牌的三要素
- **元素(系别)**：暗 an / 光 guang / 水 shui / 火 huo / 风 feng / 雷 lei / 地 di。
- **命格**：圣 sheng / 咏 yong / 血 xue / 技 ji / 幻 huan。
- **基础功能 + 可转化技能**：命格匹配的角色可把基础牌当对应职业技能打出。

## 攻击与应战（yingZhan）
- 基础攻击牌命中造成 **2 点攻击伤害**。
- 被主动攻击者可用**同系别攻击牌应战**对抗/抵消（细节随技能而变）。
- **暗灭(anMie) 无法被应战**。
- 大量技能提供"无法应战 / 无视圣盾 / 无法用圣光抵挡 / 强制命中" → **穿防/必中是关键强度点**。

## 基础效果（放置/防御）
- 圣光：抵挡一次攻击或魔弹。
- 圣盾：受攻击/魔弹时可移除以抵消该次伤害。
- 虚弱：跳过下个行动阶段（可摸 3 张取消）。
- 中毒：行动阶段前受 1 点魔法伤害，可叠加。
- 魔弹：向右手最近对手传递，命中 2 点法术伤害，可被传递/圣光/圣盾打断，每传一次 +1。

## 伤害类型
- 攻击伤害 / 法术伤害(`faShu=true`，含魔弹) / 魔法伤害(中毒等)。
- 部分技能只对特定类型生效；治疗对不同类型的抵御能力随技能变化。

## 对 AI / 决策的含义
- 应战可行性取决于"是否有同系攻击牌"；**穿防类技能让对手的应战/圣光/圣盾失效**，价值应被显著上调。
- 命格/系别决定可转化技能能否打出 → **卡组里某命格/系别牌越多，对应角色越流畅**（隐藏强度变量）。
