# 资源经济（星石 / 星杯 / 治疗 / 宝石·水晶 / 能量）

## 队伍级资源
- **士气 shiQi**：队伍生命，初始 15，→0 败。
- **战绩区 zhanJi**：每队数组，最多 `zhanJiMax`(默认5) 个**星石**；星石分 **[宝石]baoShi** / **[水晶]shuiJing**。
- **星杯 xingBei**：每队计数，达 `xingBeiMax`(默认5) 即胜。

## 个人级资源
- **治疗 zhiLiao**：基础上限 2，承伤优先抵消（防爆牌）。
- **[宝石]/[水晶]**：发动很多技能的费用（技能名前缀标记）。
- **能量**：把星石"提炼"成个人能量，部分技能按能量数结算伤害。
- **角色专属指示物**：信仰/斗气/鬼火/剑气/灵感/重生/瘴气等。

## 特殊行动（content/mode 确认）
- **购买 gouMai**：摸牌 + 获得星石（战绩区有空位时通常 +1宝石+1水晶）。
- **合成 heCheng**：消耗 3 星石 → +1 星杯。
- **提炼 tiLian**：战绩区星石 → 个人能量。
- 一般需"手牌有 3 个空位"等前置；boss【御衡】把"摸3"改为"摸2+队友各摸1"。

## 对 AI / 决策的含义
- **两条胜利线并行**：爆士气 vs 冲杯。AI 必须能在两者间按局势选线（内置 AI 几乎不主动冲杯，是缺陷）。
- 资源是连招燃料：开局送水晶/宝石的角色 + 高费高强技能 = 资源引擎。
- 星石溢出可被特定技能（boss右拳·贪妄）转化为收益。
